# Neon Snake Evolution (أفعى النيون)

لعبة ويب مستوحاة من ثعبان نوكيا الكلاسيكي، مع تطويرات حديثة: شخصيات/حيوانات متعددة، مستويات، مؤثرات، وأصوات مستوحاة من الطبيعة. جاهزة للعمل كتطبيق ويب (PWA) وتمهيدًا لتحويلها لتطبيق أندرويد وربطها بموقعك.

## التشغيل محليًا
- افتح `index.html` مباشرة في المتصفح، أو شغّل خادم محلي (مستحسن لـ PWA/Service Worker):
  - `python -m http.server 8080` ثم افتح `http://localhost:8080`

## المميزات الحالية
- لعب ثعبان كلاسيكي محسّن (Canvas) يعمل دون إنترنت وبدون مكتبات خارجية.
- شخصيات قابلة للعب: ثعبان، سحلية، سلحفاة، بطريق، عنقاء (وغيرها قابلة للإضافة).
- مستويات/تقدّم وصعوبة متدرجة + نظام نقاط وأفضل نتيجة.
- ثيمات وساحات متعددة وإعدادات (جدران، عوائق، شبكة...).
- أصوات ومؤثرات (Web Audio) مع نمط أصوات طبيعية.
- ملف تعريف محلي ونقاط محفوظة محليًا + واجهة تسجيل دخول (جاهزة للربط لاحقًا).
- أساس PWA: `manifest.webmanifest` و `sw.js` وأيقونات.
